# node (CLI)

Stamp a **limb** of this house. Same Mojo, named body — not a second throne.

```
xlii node setup                 # names it node1, node2, …
xlii node setup node1 --remote node1
xlii node setup --remote node1 --gig kimi
```

Limbs are **nodeN**, not hostnames. One JID per body (`node1@`) — same as
`throne@`, not a second `*desk` account. Phone DMs that JID. `/remote-control
open` on Face (no `/xsu`) or phone `/xsu` then `/remote-control` makes that
Conversations contact Mojo + `$` lab until drop or 5 minutes idle.
Management key never leaves the throne. `--new-key` / `--mint-xai` are reserved
options (dedicated SSH key; capped child key).

Face: **Xlii → Install node…** (`install://`).
